The Protocol
01 Connect Any Unit

Install the RoboNX agent on any robot. It auto-discovers peers, establishes an encrypted mesh, and joins the swarm in seconds. Supports ROS2, custom protocols, and direct C/Python SDK bindings.

02 Define the Mission

Write high-level objectives in RML. The coordination engine decomposes tasks, assigns them to optimal units, and maintains synchronized global state across the entire fleet in real time.

03 Let the Swarm Execute

The distributed runtime handles everything: collision avoidance, load balancing, failure recovery, continuous replanning. You set the objective — RoboNX delivers the outcome.
